# LEARNING-BRIEF.md 格式

`LEARNING-BRIEF.md` 是 BLCaptain 学习工作台的指南针。它要短、具体、可验证。

```md
# 学习任务: {主题}

## 为什么学
{1-3 句。写真实用途，不写“提升自己”这种空话。}

## 一天/一周/本阶段学成什么样
- {可观察结果 1}
- {可观察结果 2}
- {可交付产物或考核方式}

## 已有基础
- {用户已经会什么}
- {用户明确不会什么}

## 约束
- 时间:
- 工具:
- 语言:
- 资料访问:
- 其他:

## 暂不做
- {避免跑偏的相邻主题}
```

规则:

- 一个工作区只放一个主学习目标。
- 目标变化时直接更新，不保留过期方向。
- 如果简报超过一屏，说明它已经变成计划书，需要压缩。
