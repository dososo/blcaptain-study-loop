# progress/000N-slug.md 格式

`progress/` 只记录已经证明掌握、会影响下一步教学的事实。不要写流水账。

```md
# {这次真正掌握了什么}

## 已掌握
{1-3 句，说明用户现在能做什么，为什么这会改变后续教学。}

## 证据等级
{E2 应用 / E3 迁移。不要为 E0 覆盖或 E1 复述创建正式 progress。}

## 证据
- {练习结果、回答、产物、修正过的误解}

## 下一步影响
- {以后可以跳过什么}
- {下一步可以挑战什么}
```

什么时候写:

- 用户完成练习并表现出理解。
- 用户说明自己已有基础，且足够具体。
- 一个误解被纠正。
- 学习目标发生变化。
- 用户达到 E2 或 E3 证据等级。

什么时候不写:

- 只是讲过。
- 只是列了资料。
- 只是用户说“懂了”，但没有证据。
- 只能复述概念，但还不能应用。
