# 能交付一个最小可用的图片分镜 skill

## 已掌握

学习者能把 skill 从想法推进到可安装、可校验、可前测的 MVP，并能说明哪些内容属于第一版边界。

## 证据等级

E2 应用。

## 证据

已定义最小可用 skill 的四个组成部分:

- 触发条件: 用户提供或描述图片，并希望生成视频分镜提示词。
- 工作流: 图片事实拆解、创作意图确认、镜头列表、逐镜 prompt、连续性约束、负面提示词。
- 输出格式: `STORYBOARD-PROMPT-PACK.md`。
- 验证方式: 用模拟图片描述做 forward test，并检查事实/推断分离。

## 为什么这算 E2

这不是只看过 skill 创建规范，而是已经把一个真实创作目标转成了可实现的 skill 输出契约和验证方式。

## 下一步影响

- 下一轮不再讨论“要不要做”，而是测试输出质量。
- 重点转向 prompt pack 的可执行性、连续性和模型适配。
