# 能用 forward test 验证分镜提示词质量

## 已掌握

学习者能用模拟图片描述生成结构化 prompt pack，并用质量门禁判断输出是否适合进入下一轮真实图片测试。

## 证据等级

E2 应用。

## 证据

示例 forward test 输入:

```text
一张产品海报: 桌面上有一只银色金属水杯，背景是清晨厨房，侧逆光，画面干净，品牌想表达耐用和轻量。
```

输出必须包含:

- 图片事实: 水杯、桌面、厨房、侧逆光、干净画面。
- 创作推断: 耐用、轻量、清晨生活感。
- 4 个镜头: 建立环境、产品近景、材质细节、品牌收束。
- 连续性约束: 同一水杯、同一光线方向、同一厨房环境。
- 负面提示词: 避免变形、错字、多余手指、品牌 logo 幻觉。

## 为什么这算 E2

学习者已经用一个输入样例产出可检查的 prompt pack，并能指出哪些字段来自事实、哪些字段属于创作建议。

## 下一步影响

- 下一步必须使用真实图片，而不是继续模拟。
- 如果真实图片复杂，先增加“事实锁定”步骤，再扩展镜头数量。
