# 图片分镜 skill 资料清单

## S1 一手来源

- skill-creator system skill  
  用途: 确认 Codex skill 的基本结构、frontmatter、资源组织和校验方式。  
  可信原因: Codex 内置 skill 创建规范。  
  新鲜度: 2026-06-08 已检查。  
  访问性: 安装 Codex 后可在本地 skill 目录中查看。

- 目标视频模型官方文档  
  用途: 确认模型是否支持图片输入、时长、运动强度、负面提示词和分辨率参数。  
  可信原因: 参数能力必须以模型官方文档为准。  
  风险: 不同模型更新频繁，示例不写死具体版本。

## S2 专家资料

- 影视分镜和镜头语言基础  
  用途: 区分镜头大小、机位、运动、转场和节奏。  
  可信原因: 影视制作通用概念。  
  风险: 只能辅助 prompt 结构，不等于模型必然按影视术语执行。

- 创意提示词案例拆解  
  用途: 学习如何把主体、环境、动作、光线、情绪和限制拆成可检查字段。  
  风险: 案例常有平台差异，不能直接当通用事实。

## S3 工作流资料

- 真实图片输入样例  
  用途: 检查 skill 是否区分看见的事实和合理创作推断。  
  风险: 示例当前使用模拟图片描述，开源用户需要替换为自己的图片。

- 创作者验收反馈  
  用途: 判断 prompt pack 是否能直接进入视频生成工具。  
  风险: 视觉偏好主观，必须用质量门禁降低随意性。

## 资料使用策略

- 先建立通用分镜结构，再为具体模型做适配。
- 所有图片事实必须来自用户提供的图像或描述。
- 推断内容要标注为创作建议，不能写成画面事实。
- 评价输出时同时看: 可执行性、连续性、画面一致性、负面约束、模型可迁移性。

## 仍需补充

- 真实图片 forward test。
- 不同视频模型的参数适配卡。
- 创作者对 prompt pack 的实际反馈。
