# 学习任务: 一天内做出图片转视频分镜提示词 skill

## 为什么学

学习者要把一个模糊想法变成能安装、能校验、能前测的 Codex skill，用于根据图片生成视频分镜提示词。

## 本阶段学成什么样

- 能定义 skill 触发场景和输出格式。
- 能写出 `SKILL.md`、模板和 reference。
- 能完成一次 forward test。

## 已有基础

- 已了解 Codex skill 最小结构。
- 已能写 Markdown 和简单 HTML。

## 约束

- 时间: 一天内。
- 工具: Codex、skill-creator、quick_validate.py。
- 语言: 中文为主。
- 资料访问: 官方文档和本地规范优先。

## 暂不做

- 不接视频生成 API。
- 不覆盖所有视频平台参数。
