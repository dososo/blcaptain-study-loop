# 学习任务: 一天内做出图片转视频分镜提示词 skill

## 为什么学

学习者要把“根据图片生成视频分镜提示词”从一个模糊想法推进成可安装、可校验、可前测的 Codex skill。目标不是研究所有视频模型，而是今天拿到一个能帮助创作者稳定产出分镜提示词包的 MVP。

## 本阶段学成什么样

一天结束时应有:

- 一个能触发的 `SKILL.md`。
- 一个结构化分镜提示词模板。
- 一个 reference，说明镜头、运动、主体连续性、负面提示词和模型适配。
- 一个 forward test，用模拟图片说明验证输出质量。
- 一份复盘，说明下一轮要补真实图片测试还是模型参数适配。

## 目标路由

类型: 交付型 + 创作型。

原因:

- 用户要求“今天做出可用 skill”，所以第一优先级是可安装和可前测。
- 输出是创作辅助材料，需要评价量表，而不只是技术清单。
- 每轮产物都要接近真实使用场景: 图片事实、分镜、提示词、连续性约束。

## 已有基础

- 已了解 Codex skill 的最小结构。
- 能写 Markdown、模板和简单 HTML。
- 对视频提示词有直觉，但缺稳定的分镜结构。

## 约束

- 时间: 一天内。
- 不接视频生成 API。
- 不覆盖所有视频平台参数。
- 不假装识别图片中看不见的事实。
- 必须能把“图片事实”和“创作推断”分开。

## 暂不做

- 不做真实视频生成。
- 不做复杂镜头数据库。
- 不做所有模型的完整参数映射。
- 不把 prompt 写成一段不可检查的长文本。

## 第一轮最小交付

1. 写清 skill 触发条件。
2. 定义 prompt pack 输出结构。
3. 用一个模拟图片描述跑 forward test。
4. 用质量门禁判断输出是否能被创作者继续使用。

## 证据门槛

- E0: 看过视频提示词写法。
- E1: 能说出镜头、运动、主体、氛围等元素。
- E2: 能生成一份结构化 prompt pack，并通过质量门禁。
- E3: 能把同一套规则迁移到不同图片类型，并发现连续性或事实幻觉问题。
