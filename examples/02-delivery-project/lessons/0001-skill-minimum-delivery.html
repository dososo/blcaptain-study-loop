一天 MVP交付型 + 创作型

一个图片分镜 skill，最小可交付不是“会写 prompt”

它至少要能触发、能输出结构化 prompt pack、能区分图片事实和创作推断、能跑一次 forward test。

为什么不是普通对话

普通对话会直接给一段分镜 prompt。这个 skill 要留下可复用工作流，让下一张图也能稳定产出。

1. 触发条件

用户提供图片或图片描述，并希望生成视频分镜提示词。

不触发: 用户只是问图片好不好看。

2. 输出契约

输出不是一段长 prompt，而是一份 STORYBOARD-PROMPT-PACK.md。

结构越清楚，越容易验证。

3. Forward test

用一个模拟图片描述跑完整流程，检查事实、镜头、连续性和负面约束。

Prompt pack 骨架

# STORYBOARD-PROMPT-PACK

## Image Facts
只写图里能看见的事实。

## Creative Intent
用户目标、情绪、用途和节奏。

## Shots
1. 镜头大小 / 机位 / 运动 / 主体动作 / prompt

## Continuity Locks
主体、光线、环境、颜色、材质。

## Negative Prompts
避免事实幻觉、变形、错字、额外物体。

练习: 哪句话不能写进 Image Facts?

候选句判断
桌面上有一只银色金属水杯。可以，来自画面事实。
品牌想表达耐用和轻量。不能放事实，应放 Creative Intent。
背景是清晨厨房，侧逆光。可以，如果图片里确实可见。
杯子里装着热咖啡。不能，除非图片可见或用户说明。

本节产物

本节结束后，progress 只能记录“能定义可交付 skill 输出契约”，还不能记录“能适配所有图片”。这就是证据门控。
