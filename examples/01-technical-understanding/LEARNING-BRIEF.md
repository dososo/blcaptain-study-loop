# 学习任务: 30 分钟讲清 `useEffect` 依赖数组

## 为什么学

学习者写 React 组件时经常遇到 effect 重复执行、闭包值过期和依赖数组警告。目标是在 30 分钟内能解释依赖数组的作用，并能修一个常见 bug。

## 本阶段学成什么样

- 能区分 render、effect 执行和 cleanup。
- 能判断依赖数组里应该放什么。
- 能修正一个遗漏依赖导致的陈旧值问题。

## 已有基础

- 会写简单 React 组件。
- 对 hooks 有基本使用经验。

## 约束

- 时间: 30 分钟。
- 工具: 浏览器、React 文档、一个小练习。
- 语言: 中文解释，保留英文术语。
- 资料访问: 官方文档优先。

## 暂不做

- 不讲 React 并发渲染细节。
- 不讲所有 hooks。
