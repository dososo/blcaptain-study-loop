Rust CLI 契约检查卡

交付前必过

1. 用户

  • 谁会运行这个命令？
  • 他熟不熟悉 Rust？如果不熟，错误提示必须更直白。
  • 他是在本地、CI，还是共享机器上运行？

2. 命令

  • 动词是否具体: process、check、explain。
  • 参数是否暴露输入和输出，不藏在内部假设里。
  • --help 是否有真实例子。

3. 输出

  • 输出给人看，还是给程序读？
  • 是否稳定到能被下游脚本依赖？
  • 是否需要 --format json 或 --quiet？

4. 失败

  • 缺文件、格式错、不可写、未知错误是否分开？
  • stderr 是否给修复动作？
  • 退出码是否能被测试或 CI 使用？

最小验收句

一个不熟悉项目细节的团队成员，能只看 README 和 --help，用一个真实输入跑出可用输出，并能看懂至少两个失败提示。
