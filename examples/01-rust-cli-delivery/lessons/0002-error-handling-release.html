4

本节验收 4 类失败场景：缺文件、格式错、输出不可写、未知错误。

如果只会写成功路径，这个 CLI 还不能内部发布。

缺文件

不要 panic。显示路径、原因和下一步。

error: input not found
path: ./sample/in.txt
try: check the file path

格式错

尽量告诉用户行号、字段或示例格式。

error: invalid row
line: 18
expected: name,email

不可写

输出目录不存在或权限不足，要说清楚。

error: cannot write
out: ./report/result.json
try: create directory

未知错误

保留简短说明，日志另存，不把堆栈扔给用户。

error: internal failure
run with --verbose
report: issue template
