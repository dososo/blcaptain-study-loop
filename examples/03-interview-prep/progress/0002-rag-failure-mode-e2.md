# 能回答一个 RAG 失败模式追问

## 已掌握

学习者能针对“RAG 答案不准”给出诊断路径，而不是只说“调 prompt”或“换模型”。

## 证据等级

E2 应用。

## 证据

已形成压力追问回答:

```text
如果 RAG 答案不准，我会先区分三类问题:
1. 召回问题: 相关资料有没有被检索到。
2. 上下文问题: 检索到了但 chunk、排序或拼接让模型误解。
3. 生成问题: 上下文足够，但模型没有按资料回答。

对应动作是看检索样本、调 chunk 和 rerank、加引用约束，再设计离线评测。
```

## 为什么这算 E2

学习者已经能把一个开放追问拆成诊断路径，并给出有顺序的改进动作。

## 下一步影响

- 下一轮应迁移到真实业务场景，争取 E3。
- 准备一个取舍回答: 提升召回可能增加上下文噪声和延迟。
