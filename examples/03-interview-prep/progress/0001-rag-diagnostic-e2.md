# 能用 90 秒结构回答 RAG 基础问题

## 已掌握

学习者能在面试场景下解释 RAG 的基本链路，并能区分检索失败、生成失败和上下文组织失败。

## 证据等级

E2 应用。

## 证据

已完成诊断练习:

- 能说明 RAG 的目的: 把外部知识引入生成上下文。
- 能描述链路: query -> retrieve -> rerank/choose -> assemble context -> generate -> cite/evaluate。
- 能回答“RAG 是否能消除幻觉”: 不能，只能在资料可检索、上下文组织正确、模型按上下文回答时降低风险。
- 能说出 2 个失败模式: 召回不到、检索到但上下文污染。

## 为什么这算 E2

学习者不是只复述定义，而是在诊断题里判断了边界和失败模式，具备面试回答的应用能力。

## 下一步影响

- 下一轮进入压力追问: 召回差怎么办、幻觉怎么办、延迟高怎么办。
